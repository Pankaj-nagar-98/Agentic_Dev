# Agentic Development Repository

This repository contains projects developed as part of the Agentic AI curriculum:

1. **TaskFlow &bull; Modern React Todo Web Application**
2. **Food Ordering CLI Application (`main.py`)**

---

## 1. TaskFlow &mdash; React Todo Web Application

A clean, responsive, and modern Todo web application built with React and Vanilla CSS.

### Key Features
- **Authentication**: Email/password login with input validation and 1-click demo user fill (`student@example.com` / `password123`).
- **Todo Management**: Add, complete, and delete tasks with real-time UI feedback.
- **Filters & Badges**: Filter tasks by `All`, `Active`, and `Completed` with dynamic count badges and remaining task indicators.
- **Persistence**: Preserves user session and todo list using browser `localStorage`.
- **Responsive & Modern Design**: Glassmorphic layout, customized controls, and subtle micro-animations.

### Running Locally
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
